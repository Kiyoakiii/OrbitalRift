# Феникс

Начни с `Boss/PhoenixBoss.asset`. Shots — самостоятельные выстрелы, Abilities — самостоятельные способности, VFX — профили цвета, хвоста и затухания, Prefabs — объекты для общего пула. Ссылки можно назначать другим боссам и мобам. Для независимой настройки сделай копию ассета, иначе изменение применяется ко всем владельцам.

Полная инструкция: `Docs/BOSS_ASSET_SYSTEM_GUIDE.md` в корне проекта.
