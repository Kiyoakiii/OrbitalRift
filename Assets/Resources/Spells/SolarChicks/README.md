# Солнечные птенцы / Solar Chicks

Три маленькие огненные птицы вылетают из Феникса веером. У каждой читается тело,
двигается крыло, за ним тянутся огненные ленты, редкие угольки и тонкий шлейф.
Контакт завершается отдельной вспышкой, кольцом, искрами и коротким огненным остатком.

Это существующая способность **«Птенцы»**, а не новое оружие с другим балансом.
Количество снарядов, веер, скорость, время жизни и урон задаёт прежний GameManager.
В Sandbox птенцы визуально попадают в корабль без потери щитов и очков.

## Где что лежит

| Путь внутри SolarChicks | Назначение |
|---|---|
| `Prefabs/SolarChick.prefab` | Один летящий птенец; способность выпускает три экземпляра |
| `Prefabs/SolarChickImpact.prefab` | Отдельное попадание |
| `Profiles/SolarChicks.asset` | Общие параметры света, следов, частиц, impact |
| `Scripts/SolarChickMotion.cs` | Только уникальное движение птицы и PNG-лент |
| `Shaders/SolarChickWing.shader` | Деформация крыла и огненных изображений на GPU |
| `Meshes/AnimatedCard.asset` | Сетка 24×16 ячеек, на которой может изгибаться PNG |
| `Materials/` | Собственные материалы этого spell |
| `Textures/` | Копии используемых исходных PNG и небольших масок |

## Что переиспользуется

Код из `Spells/_Shared/Scripts`:

- **SpellProjectileVfx:** следует за игровым Projectile, управляет ядром, glow,
  TrailRenderer и частицами; выключает тело и даёт хвосту дожить.
- **SpellVfxProfile:** те же параметры, что у Plasma Bolt. Другой spell — другой asset.
- **SpellImpactVfx:** общая последовательность Flash → Ring/Sparks → Mist/Aftermath.
- **SpellVfxPool:** существующий ObjectPool для нескольких prefab; каждому возвращается
  его собственный визуал и используется его собственный impact.
- **SpellVfxMotion:** небольшой дополнительный компонент с Begin/Tick/End для уникальной
  анимации. У Plasma Bolt он не нужен; у птенца его реализует SolarChickMotion.
- **SpellVfxPreview:** проигрывает тот же prefab в уже существующей панели «Слои VFX».

Нового универсального VFX-редактора нет. Обычный Plasma Bolt сохраняет свой профиль.
Лунный вариант можно делать по прежнему примеру в README Plasma Bolt.

## Из каких слоёв состоит птенец

| Объект | Компонент | Для чего нужен |
|---|---|---|
| Bird | MeshRenderer, сетка, SolarChickWing | Узнаваемая PNG-птица. Голова стабильна, верхняя часть крыла складывается |
| Heart | MeshRenderer | Небольшой горячий акцент под телом, связывает птицу с энергетическим ядром |
| Glow | MeshRenderer | Слабый ореол вокруг птицы, не закрывает лицо |
| Trails/MainTrail | TrailRenderer | Тонкая реальная история мировых позиций, показывает направление |
| SecondaryMotion/Ribbon_A, Ribbon_B | TrailRenderer | Два дополнительных следа от движущихся точек вокруг оси полёта |
| FlameLeft, FlameRight | MeshRenderer, сетка, SolarChickWing | PNG огненных перьев изгибаются и покачиваются с разными фазами |
| Particles/MainParticles | ParticleSystem, Texture Sheet Animation | Небольшие фрагменты PNG с огненными искрами разлетаются отдельно |
| Particles/MicroParticles | ParticleSystem | Мелкие угольки дают второй масштаб деталей |
| Impact/Flash | MeshRenderer | Короткая вспышка контакта |
| Impact/Ring | MeshRenderer | Расширяющаяся волна |
| Impact/Sparks | ParticleSystem | Однократный разлёт небольших искр |
| Impact/Mist | MeshRenderer | Очень слабое остывающее облачко |
| Impact/Aftermath | MeshRenderer | Поздний остаточный рисунок огня; это свечение в воздухе, не след на поверхности |

## Как PNG вообще двигается

PNG — это изображение, а ParticleSystem — способ выпускать и двигать элементы.
Одно не мешает другому. Здесь применяются два разных способа.

**Птица и ленты:** PNG лежит на сетке, а не на плоском quad из двух треугольников.
Шейдер смещает вершины сетки. У птицы верхняя левая часть изображения считается
крылом; движение там сильнее и постепенно сходит на нет около головы.
Это имитация взмаха из одной картинки, не покадровая анимация и не полный скелет.
Большой Wing Fold растягивает рисунок — поэтому стандартное значение умеренное.

Ленты имеют другую формулу деформации: волна идёт вдоль изображения и сильнее
двигает его свободный край. Их фаза отличается от взмаха, поэтому огонь не выглядит
жёстким украшением, приклеенным к птице.

**Искры:** исходная картинка EmberAtlas разделена UV-координатами на сетку 4×4.
Каждая Unity-частица получает случайный участок этой картинки и своё время жизни,
размер, скорость и вращение. Исходник не является специально нарисованным атласом:
это намеренное использование небольших фрагментов огня, а не 16 кадров анимации.
Для другого рисунка можно заменить atlas и перенастроить Texture Sheet Animation.

На PNG огня есть тёмная синеватая подложка. Материал убирает её по яркости и
тёплому оттенку непосредственно в shader. Исходные изображения не перерисовывались.
У самой птицы сохраняется её прозрачность и цвет: тёмный глаз остаётся видимым.

Для Bird используется alpha blending, чтобы цвет и лицо не выбеливались при наложении.
Для огня — additive. Для Mist — alpha blending. `_TextureColor = 1` сохраняет RGB
рисунка; `_KeyDarkPlate = 1` убирает тёмную подложку. У белых масок оба параметра выключены.
В стандартных материалах Plasma Bolt новые параметры выключены по умолчанию.

## Движение и время

**Primary:** старый Projectile летит по Velocity. Анимация не меняет этот вектор.
**Secondary:** взмах крыла, огненные PNG-ленты и три настоящих следа.
**Tertiary:** угольки, случайные фрагменты и лёгкое покачивание тела.

Птица и ленты находятся в локальном пространстве визуала. Обе системы частиц —
World: выпущенные угольки остаются за птенцом. TrailRenderer тоже хранит мировой путь.
Соседние птенцы получают разные фазы, а не машут крыльями одновременно.

Первые 0.12 с птица раскрывается от 35% до полного размера. Во время полёта крыло
совершает около 3.6 взмаха в секунду. При контакте Bird, Heart и Glow выключаются;
ленты-изображения исчезают, а уже выпущенные частицы и следы спокойно затухают.

При Impact Duration = 0.9 с: Flash длится около 0.08 с, Ring до 0.315 с,
искры живут примерно 0.16–0.45 с, Mist появляется после 0.05 с,
Aftermath — после 0.25 с и затухает к концу. Истечение Life не создаёт ложного удара.

## Главные настройки: профиль SolarChicks.asset

| Параметр | Что означает | Больше | Меньше |
|---|---|---|---|
| Core Size | Размер маленького Heart, не всего PNG-птенца | Горячий центр сильнее | Центр спокойнее |
| Core Color | Оттенок Heart | Светлее — горячее | Темнее — меньше акцент |
| Core Brightness | Яркость Heart и ограниченная яркость птицы | Центр ярче | Тише свечение |
| Glow Size / Brightness | Площадь и сила ореола | Больше энергии и наложений | Лучше отделяется силуэт |
| Trail Width | Толщина основного следа | Тяжелее и мощнее | Тоньше и быстрее по ощущению |
| Trail Lifetime | Сколько секунд остаётся след | Длиннее хвост | Короче и резче |
| Trail Color | Цвет и alpha от головы к концу | Светлее/плотнее хвост | Меньше конкуренции с птицей |
| Trail Shape | Сужение следа | Толще выбранный участок | Острее кончик |
| Particle Count | Частота выпуска PNG-фрагментов | Гуще огонь | Чище рисунок |
| Micro Count | Частота мелких угольков | Больше фактуры | Спокойнее |
| Particle Size | Размер фрагментов; micro в 0.4 раза мельче | Заметнее кусочки огня | Тонкая пыль |
| Particle Speed | Скорость разлёта | Шире облако | Плотнее шлейф |
| Particle Lifetime | Время жизни | Больше одновременно живущих частиц | Быстрее очищается экран |
| Particle Color | Дополнительный оттенок искр | Ярче каналы — ярче искры | Темнее каналы — слабее искры |
| Noise Strength | Неровность путей частиц | Более бурный огонь | Ровнее движение |
| Secondary Motion Speed / Radius | Темп и размах точек Trail-лент | Больше витков/разлёт | Плотнее и спокойнее |
| Impact Size / Brightness | Масштаб и яркость попадания | Мощнее, больше overdraw | Компактнее |
| Impact Particle Count | Искры за одно попадание | Больше разлёта | Чище |
| Impact Duration | Общая длительность | Дольше остаток | Быстрее удар |

Расшифровка служебных YAML-полей `key0`, `ctime`, `m_Curve`, `inSlope` и других
та же, что в [разделах 14.1–14.2 Plasma Bolt](../PlasmaBolt/README.md#141-как-читать-trailcolor-в-файле-профиля).
Для обычной настройки открывай градиент/кривую в Inspector, а не редактируй номера вручную.

## Уникальные настройки: компонент SolarChickMotion в prefab

| Параметр | Что меняет | Больше | Меньше |
|---|---|---|---|
| Bird Size | Размер всей PNG-птицы | Крупнее силуэт | Меньше и легче |
| Wing Beat Speed | Взмахи в секунду | Более торопливый птенец | Плавнее парение |
| Wing Fold | Сила складывания крыла | Выразительнее взмах, сильнее деформация PNG | Более стабильный силуэт; 0 фиксирует крыло |
| Body Bob | Маленькое поперечное покачивание | Живее, но менее устойчиво | Спокойнее |
| Bank Angle | Покачивание угла тела | Заметнее наклон | Ровнее полёт |
| Flame Size | Размер PNG огненных лент | Шире огненное оперение | Компактнее |
| Flame Sway | Сила изгиба PNG-лент | Больше волн | Ровнее рисунок |
| Flame Brightness | Яркость PNG-лент | Ленты важнее | Птица читается лучше |

Это параметры **визуала**. Они не увеличивают урон, хитбокс или скорость projectile.
На полях есть русские Tooltip-подсказки. Bird/FlameLeft/FlameRight — ссылки на слои,
их не нужно очищать при настройке размеров.

## Как посмотреть и изменить

1. `Boot.unity → Play → Песочница способностей`.
2. Нажми карточку **Птенцы**; в стандартном наборе это клавиша **1**.
   Если состав набора изменён, ориентируйся на цифру, показанную на карточке.
3. В Sandbox Феникс выпускает веер в сторону корабля. Двигайся A/D, чтобы сравнить
   полёт и уклонение. Кнопка скрытия босса продолжает убирать его снаряды.
4. Для изучения слоёв открой **Слои VFX**, выбери **Птенцы**. Здесь проигрывается
   тот же prefab; переключатели скрывают его реальные компоненты.
5. Цвета/следы/частицы меняй в `Profiles/SolarChicks.asset`, взмах и размер птицы —
   в `Prefabs/SolarChick.prefab → SolarChickMotion`.
6. После изменения prefab перезапусти Play Mode: уже созданные объекты пула могут
   сохранять старые значения. Профиль читается при выстрелах, часть его параметров — каждый кадр.
7. Масштаб/яркость в панели — параметры предпросмотра. Они меняют временную копию
   профиля и не записывают изменения в исходный asset. Для постоянного изменения используй Inspector.

Слои панели: Core = Bird + Heart; Ribbons = PNG-ленты + две Trail-ленты;
Trail = MainTrail; Particles = две системы частиц; Noise = покачивание корпуса;
Glow = ореол; Impact = Flash/Ring/Sparks; Decal = Mist/Aftermath.
На карточках показаны используемые текстуры; карта Noise показывает материал ленты
как иллюстрацию движения, а не отдельную «текстуру шума».

## Как сделать вариант

1. Дублируй папку SolarChicks в Unity Project, например в EmberOwls.
2. Назначь дубликату prefab его новый профиль и новый impact.
3. Переназначь скопированные материалы и текстуры, чтобы изменения не затрагивали оригинал.
4. Для медленного парящего птенца попробуй Wing Beat Speed = 1.5, Wing Fold = 0.3,
   Body Bob = 0.01, Trail Lifetime = 0.32 и Particle Count = 10.
5. Меняй цвет огня сначала материалами/профилем. У исходной PNG-птицы уже тёплые
   цвета: простое умножение на синий не превратит её в качественную синюю птицу.
   Для принципиально другой палитры лучше подготовить соответствующее изображение.
6. Если меняешь позу картинки, проверь зону деформации в SolarChickWing: она рассчитана
   на нынешнее изображение, смотрящее вправо. У другого рисунка крыло может быть в другом месте.
7. Назначь новый prefab в поле **Solar Chick Prefab** у GameManager перед Play Mode.
   Новый C# не нужен, пока различаются только параметры и картинки.

## Производительность

Нет realtime lights, покадрового создания материалов или пересборки сетки на CPU.
Сетка небольшая и общая; деформация вычисляется на GPU. Исходная PNG птицы при импорте
ограничена 512 пикселями, остальные цветные слои — 256. Исходные файлы сохранены без изменения.

Общий gameplay-пул ограничен 64 активными визуалами и 24 impacts суммарно для spells.
Для птенцов заранее создаются 12 визуалов и 8 impacts; для Plasma остаётся его прогрев.
Предпросмотр имеет собственный маленький пул на три выстрела и три попадания.
При нехватке лимита выстрел сохраняет прежний игровой визуал и поведение.

Основная цена — прозрачные огненные изображения и наложения. Если тяжело,
сначала уменьши Flame Size и Glow Size, затем Particle Count и Trail Lifetime.
На телефоне результат нужно отдельно проверить профайлером; Editor не заменяет Android GPU.

## Повторная проверка

Вне Play Mode: **Orbital Rift → Spells → Validate Solar Chicks in Sandbox**.
Кадры и отчёт сохраняются в `Docs/VFX_Evidence/SolarChicks`.
Отдельная команда проверки Plasma Bolt проверяет, что общие изменения не сломали первый spell.
