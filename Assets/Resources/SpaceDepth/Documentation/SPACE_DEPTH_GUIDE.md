# Space Depth System — слои и ручная сборка

Космос разделён на слои с разными скоростью, размером, контрастом и параллаксом.
Gameplay остаётся двумерным. Phase 2 добавляет управление курсом и смещение центра
орбиты: [COURSE_STEERING_GUIDE.md](COURSE_STEERING_GUIDE.md). Назначение материалов,
текстур и спрайтов: [ARTWORK_GUIDE.md](ARTWORK_GUIDE.md). Гравитация не добавлена.

## Где искать

- Профиль: `Assets/Resources/SpaceDepth/Profiles/SpaceDepthProfile.asset`.
- Runtime hierarchy: `SpaceDepthRoot`, внутри 12 подписанных слотов.
- `Scripts/SpaceDepthProfile.cs`: общие данные и стартовые значения.
- `Scripts/SpaceFlightVisualController.cs`: скорость, точка схода, Solo, Reset, Save.
- `Scripts/SpaceDepthLayer.cs`: пакетная геометрия и переиспользование элементов.
- `Shaders/SpaceDepth.shader`: процедурные формы звёзд, галактик, облаков,
  планет, камней и стриков. Это обычный локальный Unity shader.
- `Assets/Scripts/GameManager.SpaceDepth.cs`: небольшой адаптер существующей игры.
- Технический аудит — [AUDIT.md](AUDIT.md).

## Слои

| № | Слой | Depth | Speed | Что даёт |
|---|---|---:|---:|---|
| 1 | Deep Space | 0 | .008 | Тёмная протяжённая основа, минимальный контраст |
| 2 | Distant Galaxies | .05 | .025 | Один приглушённый спиральный силуэт |
| 3 | Far Stars | .10 | .13 | Маленькие точки без хвостов |
| 4 | Nebula | .15 | .025 | Три облака с нитями, пустотами и внутренним дрейфом |
| 5 | Distant Planets | .20 | .055 | Выключена; по желанию одна небольшая планета |
| 6 | Mid Stars | .35 | .42 | Более крупные и быстрые точки |
| 7 | Far Streaks | .45 | .65 | Тонкие умеренные линии потока |
| 8 | Asteroids | .55 | .42 | Три класса обломков; крупные проявляются за пределами центра |
| 9 | Mid Streaks | .70 | 1.20 | Основное ощущение движения |
| 10 | Music Rings — внешний | .75 | — | Существующий музыкальный визуализатор, не изменён |
| 11 | Near Streaks | .90 | 2.10 | Редкие быстрые пролёты у края |
| 12 | Foreground Dust | 1 | 1.60 | Резкие точки, мягкие частицы и редкая ближняя дымка |

По уточнению пользователя слот 10 информационный. Здесь нет второй системы колец.
Solo/Hide/Reset и скорость Space Depth не меняют музыку и её кольца. Поэтому
управляемых новых слоёв 11, а структура профиля содержит 12 слотов.

Все новые слои используют **MeshRenderer**: звёзды и стрики объединены в один mesh
на слой, крупные тела хранят собственные позиции, вращение и размеры в его буфере.
Новые ParticleSystem не нужны. Уже существующие ParticleSystem заклинаний сохранены.
У каждого слоя фиксированный запас элементов (`Capacity`); они циклически переиспользуются,
без Instantiate/Destroy при пролётах. Фиолетовые pickups по-прежнему используют ObjectPool.

## Настройка в Sandbox

Открой существующую песочницу и нажми **SPACE DEPTH · слои космоса** внизу справа.
В панели можно прокручивать список. Закрытие панели возвращает обычный интерфейс.

Вверху: скорость космоса, пауза только космоса, связь скорости с боем/переходом,
показ/скрытие всех управляемых слоёв, сброс и загрузка сохранённого профиля.
При открытии панели связь с боевой скоростью выключается, чтобы значения ползунка
можно было сравнивать напрямую. Её можно включить отдельной галочкой.

Выбери слой, затем **SOLO**: остальные Space Depth слои скрываются, gameplay и
музыкальные кольца остаются. **Все** снимает Solo. **Сбросить выбранный слой**
возвращает его значения из сохранённого asset, **Сбросить всё** — весь профиль.

Все ползунки применяются во время Play Mode. В Editor кнопка **Сохранить** переносит
текущую копию в asset через Undo / SetDirty / SaveAssets. Без сохранения изменения
исчезнут при выходе из Play Mode. В сборке сохранение asset недоступно.

## Значения и формулы

`GetTravelSpeed = GlobalTravelSpeed × внешний множитель × коэффициент боя/перехода`.
Последний коэффициент используется только при включённом FollowGameplaySpeed.
Он приходит из прежнего `GameManager.UpdateSpaceTravel`, не меняя его значения.

У радиального элемента `dr/dt = GetTravelSpeed × SpeedMultiplier × (0.35 + radius × 0.35)`.
Поэтому при удалении от точки схода apparent motion ускоряется. На границах есть
плавное появление/исчезновение, затем запись буфера переиспользуется у SpawnRadius.
При нулевой скорости и при PauseMotion радиальное движение, дрейф, шум и вращение
останавливаются. Изменение размера, яркости и Density всё равно видно сразу.

`CurrentVanishingPoint` теперь следует за CurrentCourseCenter. У каждого слоя есть
свой сглаженный EffectiveVanishingPoint. При SteeringEnabled=false все точки
возвращаются к нейтральному центру камеры, как в Phase 1.
Музыкальные кольца и игровые pickups исключены из этой системы.

Depth — художественная нормализованная глубина, а не метры. Она влияет на рост
размера по ходу полёта, параллакс камеры и амплитуду шума. Скорость задаётся отдельно:
изменение Depth не переписывает SpeedMultiplier. Порядок рисования стабилен по
порядку слоёв (-95…-40) и не переставляется при движении ползунка глубины.

SteeringInfluence задаёт силу реакции слоя на курс, SteeringResponseSpeed — скорость
отклика. Меняются в реальном времени. Подробности и безопасные границы орбиты —
в COURSE_STEERING_GUIDE.md. В Layers также доступны Appearance, Material, Texture,
Sprite и PreserveImageAspect; пустой Material использует встроенный shader.

| Параметр | Увеличение | Уменьшение |
|---|---|---|
| SpeedMultiplier | Быстрее проходит экран, сильнее скорость | Стабильнее, кажется дальше |
| Density | Больше элементов до Capacity, больше шума и нагрузки | Чище и легче |
| MinScale / MaxScale | Крупнее, кажется ближе | Мельче, кажется дальше |
| MinAlpha / MaxAlpha | Слой заметнее, может спорить с кораблём | Уходит в фон |
| Brightness | Ярче RGB | Темнее, без изменения плотности |
| Depth | Сильнее рост и параллакс | Более далёкое впечатление |
| ParallaxMultiplier | Сильнее реакция на существующее смещение камеры | Спокойнее |
| RotationSpeed | Быстрее вращаются тела | Медленнее; отрицательное — обратная сторона |
| NoiseAmount | Сильнее небольшие отклонения | Ровнее |
| Stretch | Длиннее стрики | Ближе к точкам |
| Spawn / Despawn Radius | Меняет область появления/повторного использования | Проверяй композицию у центра |

## API

`GameManager.SpaceDepth` даёт контроллер. Доступны `GetTravelSpeed()`,
`SetTravelSpeed(value)`, `SetTravelSpeedMultiplier(value)`, `ResetTravelSpeed()`.
Boost/slowdown в будущем могут использовать этот API без перебора всех слоёв.
Это пока только API: новые игровые способности скорости не добавлены.

## Производительность и новые слои

Основная цена крупных слоёв — площадь прозрачности и noise shader. Сначала снижай
размер/плотность Nebula, затем плотность звёзд. Снижение alpha само по себе не снижает
число обработанных пикселей. Capacity — заранее выделенный запас, BaseCount × Density
задаёт видимое количество. После visual pass стандартный профиль содержит 434 элемента, 10 draw
submissions космоса; точное число зависит от камер и Unity batching.

Чтобы добавить слой, расширь Layers в asset, выбери существующий Kind и задай его
параметры. Новый Kind нужен только для новой формы шейдера. Порядок массива определяет
sorting order; сохраняй запас ниже gameplay. Capacity читается при создании слоя:
при его изменении нужно заново войти в Play Mode. Основные художественные параметры
не требуют перезапуска.

## Проверка

Меню **Orbital Rift → Space Depth → Validate Far / Mid / All** запускает проверку
в Boot/Sandbox. Отчёты и кадры: `Docs/VFX_Evidence/SpaceDepth`. Захваты `solo`, `group`
и `stage` содержат только космос; `gameplay` — композицию с игрой; `sandbox-panel` — UI.
Результаты CPU относятся только к контроллеру на текущем компьютере и не заменяют
GPU-профилирование Android. Художественный проход туманностей, обломков и передней пыли
описан в `VISUAL_ART_PASS.md`; его отдельная проверка: **Art - Validate final**.
