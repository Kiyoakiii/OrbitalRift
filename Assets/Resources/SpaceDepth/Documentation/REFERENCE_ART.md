# Туманности и галактики по референсу

Текущий профиль использует три детальных облака из двух рисунков и две спиральные
галактики. Насыщенные синие и малиновые нити обрамляют тёмное игровое поле.
Планеты выключены. Курс, ввод, музыка и сцена Boot сохранены.

## Детализация

Материал смещает одну выборку изображения и не усредняет сдвинутые копии.
Чёрный RGB-фон даёт нулевой световой вклад; дополнительная вырезка alpha не нужна.
Контраст теней и мягкое ограничение самых ярких участков сохраняют рисунок нитей.
Медленное внутреннее течение связано со скоростью слоя и останавливается на паузе.

Для новых текстур включён Ignore Mipmap Limit. На ПК используется RGBA32 без
сжатия; исходные размеры подтверждены в Play Mode. Mipmaps и Trilinear сохраняют
устойчивость мелких звёзд при уменьшении. Для Android задан ASTC 4×4.

С новым материалом скрыты прежние круги свечения, чёрные пятна и линии
`SpaceNebulaClusterVisual`. Старый материал сохраняет прежнее поведение этого
компонента. Рисунки выводятся через существующий общий mesh каждого слоя.

## Sandbox

Открыть **SPACE DEPTH → Туманности / Галактики**.

- **Композиция у краёв экрана** учитывает камеру, её масштаб и пропорции экрана.
  Для галактик предусмотрены две позиции; Density не накладывает их копии друг на
  друга. Без этого переключателя действует прежнее расположение.
- **Cluster Count**: 2–4 облака, текущая композиция содержит три.
- **Cluster Size / Размер min-max**, **Brightness / Opacity**: масштаб и световой вклад.
- **Glow** усиливает свечение; **Filament** подчёркивает светлые нити;
  **Dark Voids** задаёт контраст теней; **Dust** усиливает встроенные звёздные точки.
- **Drift** задаёт слабое внутреннее течение рисунка.
- **Tint / Highlight Tint** меняют основной оттенок и оттенок ярких участков.

Основная картинка задаётся Texture/Sprite. Вторая — в материале `NebulaReference`,
поле **Alternate cloud artwork**. Для одной своей картинки поставить в материале
**Alternate variants = 0**. Обычный альфа-шейдер покажет чёрную подложку этих RGB PNG;
используемый `SpaceEmissionDetail` складывает только свет.
Профиль сохраняется кнопкой **Сохранить**, материал перечитывается кнопкой
**Обновить материалы**.

Финальный прогон с текущими настройками остальных слоёв: 531 элемент, 9 активных
рендереров, около 0.427 мс на Tick и 0 байт выделений за 240 шагов. Полный кадр
Editor — около 6.37 мс / 157 FPS. Это замер на ПК; GPU телефона не проверялся.
Основная дополнительная стоимость — память текстур и площадь прозрачных quad.

Прежний `VISUAL_ART_PASS.md` описывает предыдущую версию. Меню
**Orbital Rift → Space Depth → Reference - Apply vivid artwork** восстанавливает
только эту композицию туманностей/галактик и отключение планет. Остальные слои и
параметры курса оно не сбрасывает.
