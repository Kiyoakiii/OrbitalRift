# Course Steering — Phase 2

Продолжение Space Depth. Курс меняет оптический поток, а центр орбиты следует за
курсом. Камера не вращается. Враги и выпущенные игровые снаряды остаются в своих
мировых координатах. Гравитационная Phase 3 не реализована.

## Где открыть

В главном меню открой существующий Sandbox способностей, затем **SPACE DEPTH ·
слои космоса** внизу справа. Раскрой **КУРС · управление и диагностика**.
В обычном бою действуют те же сохранённые настройки. В меню курс сбрасывается.

Все значения хранятся в `Assets/Resources/SpaceDepth/Profiles/SpaceDepthProfile.asset`:
секция **Steering**, для отдельных слоёв — **Layers**. В Play Mode контроллер
создаёт копию профиля. **Сохранить** переносит её в asset; **Перечитать профиль**
отменяет временные настройки. Изменения исходного asset вне Play Mode сохраняет Unity.

## Управление

- I / K — курс вверх / вниз; J / L — влево / вправо. Диагонали поддерживаются.
- A / D и стрелки — прежнее движение корабля по орбите. Мышь и touch сохраняют
  прежние зоны управления орбитой. Новый экранный джойстик не добавлен.
- Левый стик — курс; правый — орбита. Осевые привязки находятся в существующем
  **Project Settings → Input Manager**: `CourseHorizontal`, `CourseVertical`,
  `OrbitHorizontal`. Клавиши курса меняются в профиле `Left/Right/Up/Down Key`.
- После отпускания курс остаётся на выбранной цели. Возврат — отдельная опция.
- Ввод блокируется при взаимодействии с панелью, редактировании текстового поля,
  открытом меню и потере фокуса. Пауза игры останавливает курс и слои.
- Кнопки 3 × 3 задают центр, стороны и диагонали. Center плавный; **Instant Reset**
  делает именно эту кнопку мгновенной. Выбор пресета отключает автотест.

## Как устроены центры

`CourseController` находится в `Scripts/CourseController.cs` этой папки SpaceDepth.
Он получает вектор через существующий `PlayerCommandFrame`, без отдельного Update.
Neutral = (0.5, 0.5) в координатах экрана. Ввод сдвигает Target за секунду, Current
плавно догоняет Target через SmoothDamp. Current переводится в мировые единицы
существующей ортографической камеры и становится общей точкой схода.

Для слоя: `TargetEffectiveVP = NeutralWorld + CourseOffsetWorld ×
GlobalSteeringStrength × SteeringInfluence`. `CurrentEffectiveVP` догоняет его
с экспоненциальным откликом SteeringResponseSpeed. Дальние слои реагируют слабее
и медленнее ближних. Depth сам по себе не переписывает эти художественные параметры.

Звёзды, астероиды, пыль и стрики сохраняют мировую позицию, плавно меняя направление
от своего EffectiveVP наружу. При повторном появлении берут новый центр. Жизненный
цикл и fade не вычисляются заново от сместившегося центра — вспышек при повороте нет.
Стрики используют четыре сегмента и историю хвоста. Звёзды без следа используют
векторное расширение от EffectiveVP: при проходе центра через звезду её скорость
плавно меняет знак без разворота по дуге. Крупные нерадиальные слои имеют медленный
противоположный параллакс.

По уточнению владельца весь существующий музыкальный визуализатор теперь следует
за общим CurrentCourseCenter. Геометрия, частицы, уже выпущенные музыкальные кольца
и их преломление используют согласованный центр. Палитра, форма и реакция на звук
сохранены. Музыка остаётся отдельной системой и не управляется полями art-слота 10.

`GameManager.ShipOrbitCenter = CourseOffsetWorld × OrbitCenterFollowStrength`.
К прежней позиции на окружности прибавляется этот центр. Радиус и угловое управление
не меняются. Нос и обычная стрельба направлены внутрь новой орбиты. Rift Echo
использует тот же центр. Коллизии и щиты используют фактическую позицию корабля.

## Настройки

| Поле | Что меняет | Стартовое значение |
|---|---|---|
| Steering Enabled | Выключение возвращает нейтральный режим Phase 1 | true |
| Course Move Speed | Скорость ввода Target, доля экрана за секунду | 0.22 |
| Course Smooth Time | Время сглаживания Current: выше = мягче | 0.28 с |
| Max Course Center Speed | Верхний предел скорости Current | 0.65 |
| Max Course Offset X / Y | Предел отклонения от середины экрана | 0.22 / 0.20 |
| Input Dead Zone | Отсекает дрейф стика | 0.16 |
| Return To Center | Возвращение после отпускания | false |
| Return To Center Speed | Скорость возврата Target | 0.22 |
| Global Steering Strength | Общая сила воздействия на слои | 1 |
| Orbit Center Follow Strength | Насколько орбита следует за курсом | 1 |
| Safe Screen Margin | Запас от края экрана в мировых единицах | 0.25 |
| Steering Influence (слой) | Амплитуда реакции слоя, 0 = нет смещения VP | 0…1 по глубине |
| Steering Response Speed (слой) | Скорость отклика слоя, выше = быстрее | 0.6…8 по глубине |

Пределы X/Y дополнительно сужаются так, чтобы окружность орбиты и запас помещались
в экран. Диагональный ввод ограничивается эллипсом, а не прямоугольником. Поэтому
на узком экране фактические пределы могут быть меньше заданных — смотри **Безопасные
пределы** в панели. Для более заметного курса сначала увеличь Max Offset, затем
Global Strength; Near Influence выше Far. Не повышай одновременно все параметры.

Для выключения: Steering → **Steering Enabled = false**, затем **Сохранить**.
Это сброс режима: текущий поворот обнуляется, радиальные элементы возвращаются к
траекториям Phase 1. Выключение не является плавным художественным переходом.

## Диагностика

В Editor / Development Build включи **Маркеры центра и слоёв**. N — белая нейтраль,
Target — жёлтая цель, Current — голубой центр, номера — EffectiveVP слоёв.
**Линии между маркерами** показывают отставание. Числа Neutral, Target, Current,
Offset и безопасные пределы доступны в панели. Музыкальный слот не рисует маркер.

Автотесты: горизонталь, вертикаль, круг и восьмёрка. Off возвращает ручное управление.
Для изолированной проверки оставь Far/Mid Stars и Far/Mid/Near Streaks; смести курс
вправо. Затем подключай туманности и планеты. Скорость полёта от курса не меняется.

Меню Unity: **Orbital Rift → Space Depth → Phase 2 - Flow checkpoint / Full
validation**. Запускать из Edit Mode. Проверка создаёт отчёты и кадры в
`Docs/VFX_Evidence/CourseSteering`. Изолированные кадры содержат только космос;
`production-course` — настоящую игровую сцену; `sandbox-course-panel` — Game View с UI.

## Изображения, производительность, ограничения

Назначение PNG, Sprite, Material подробно описано в **ARTWORK_GUIDE.md** рядом.
Форма и характер движения выбираются независимо. Собственный материал должен
поддерживать UV, vertex COLOR и прозрачность; встроенный Image shader уже это делает.

На слой — общий Mesh и материал, заранее выделенные массивы. Нет GameObject на
звезду, Instantiate/Destroy частиц и LINQ в кадре. Хвосты имеют фиксированную длину
истории. Материалы пересоздаются только при смене ссылки/режима или ручном обновлении.
Обновление настроек картинок не создаёт материалы каждый кадр.

Текущий курс подключён к классическому одиночному бою и Sandbox. Co-op, Defense и
Expedition оставлены с прежним центром: перенос сетевого/другого режима требует
согласования его симуляции, ввода и синхронизации. Физический геймпад и Android GPU
нужно проверять на целевом устройстве. Старый Input Manager имеет платформенную
нумерацию осей; правый стик при необходимости переназначается там.

Сцена Boot не изменяется. Новые speed rings не добавлены. В музыкальном визуализаторе
изменена привязка центра по уточнению владельца. Это не новая система гравитации.
