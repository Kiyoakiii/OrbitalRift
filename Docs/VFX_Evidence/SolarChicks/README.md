# Solar Chicks — проверка 11 сентября 2026

Unity 6000.3.22f1, Windows Editor, DX12. Реальный Play Mode сцены Boot.

- `validation.txt`: 24 проверки полёта, деформации PNG, частиц, попадания,
  сохранения урона, отсутствия урона в Sandbox, очистки/повторного использования
  общего пула и изоляции предпросмотра на слое 31.
- `../PlasmaBolt/validation.txt`: 18 проверок прежнего заклинания после изменения
  общего пула и шейдера. Ожидание очистки учитывает трёхсекундную жизнь промахнувшихся снарядов.
- `01` — общий полёт; `02` и `03` — две фазы взмаха; `04` — движение игрока;
  `05` — смешанные заклинания; `06` — попадание с обычным уроном.
- `07` — захват мировой камеры в режиме предпросмотра, без интерфейса.
  Карточки и подписи дополнительно осмотрены в полном окне Unity.

SHA-256 копий Chick, FlameRibbons и EmberAtlas совпадает с исходными PNG.
Анимацию выполняют сетка/шейдер и Unity ParticleSystem; изображения не перерисованы.
У старого изображения босса видна встроенная клетчатая подложка; это не слой птенцов.

Проверка выполнена в Editor. Android APK и производительность на устройстве не проверялись.
