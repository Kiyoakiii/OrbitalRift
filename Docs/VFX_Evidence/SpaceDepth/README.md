# Space Depth Phase 1 — результаты, 12 сентября 2026

Unity 6000.3.22f1, Built-in, Windows Editor/DX12, сцена Boot.
Проверки идут в реальном Play Mode. Новая структура: 11 управляемых depth layers
и информационный слот существующих музыкальных колец по уточнению пользователя.

## Результат

- `stage-1.txt`: дальние слои — PASS.
- `stage-2.txt`: дальние + средние слои — PASS.
- `stage-3.txt`: все слои, отдельные Solo и группы, нулевая скорость, Pause,
  независимая скорость, плотность, яркость, параллакс, Save/Reset, обычная игра — PASS.
- `stage-3-space.png`: новая композиция без gameplay и музыкальной обработки.
- `solo-00`…`solo-11`: кадры каждого управляемого слоя. `solo-09` намеренно нет:
  это внешние музыкальные кольца, система ими не управляет.
- `group-0/1/2`: Far / Mid / Near отдельно.
- `speed-0.08/1.80/4.00/9.00`: низкая / обычная / высокая / очень высокая скорость.
- `actual-gameplay-later.png`: обычный бой после правильного выхода из Sandbox.
- `sandbox-panel.png`: настоящий игровой UI с открытой панелью.

Первый тест запуска боя исправлен: прямой StartGame при открытом Sandbox создавал
невалидную комбинацию режимов. Финальный тест вызывает ExitAbilitySandbox,
проверяет playing=true и IsOpen=false, затем снимает кадр.

## Нагрузка

| Измерение | Результат |
|---|---:|
| CPU SpaceDepth.Tick, среднее 240 обновлений | 0.247 мс |
| Выделения managed memory за 240 обновлений | 0 байт |
| CPU при плотности ×3 | 0.732 мс |
| Элементы при плотности ×3 | 1410 |
| Managed allocations при ×3 | 0 байт |
| Полный кадр Editor, новые слои скрыты, 120 кадров | 4.51 мс / 221.9 FPS |
| Полный кадр Editor, новые слои включены, 120 кадров | 4.37 мс / 228.9 FPS |

Разницу FPS нельзя трактовать как ускорение от новых слоёв: это короткий последовательный
замер, подверженный колебаниям Editor и текущей анимации. Явной деградации здесь нет.
CPU-тест не измеряет GPU-стоимость прозрачности. Android APK и устройство не проверялись.

Музыкальные файлы `MusicReactiveVisualDirector.cs` и `MusicSpaceDistortion.cs`,
`OrbitSettings.cs` и `PlayerCommandSource.cs` не редактировались; их времена изменения
остаются до начала этой задачи. Старые предупреждения CS0162 в GameplayRulesValidator
сохраняются. Новых ошибок компиляции и ошибок во время финальной проверки нет.

Захваты отдельных слоёв выполняются временной камерой без музыкальных image effects.
Игровая камера и её компоненты не изменяются. На финальном gameplay-кадре действуют
прежние музыкальные эффекты, поэтому он отличается от изолированного пространства.
