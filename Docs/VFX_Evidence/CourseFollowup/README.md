# Устранение чёрного корабля, движение звёзд, центр музыки

Причина чёрного силуэта: `SandboxLayeredVfx → Workshop clean animation plate`.
Непрозрачная служебная подложка использовала fallback-спрайт корабля, была увеличена
до 30 × 30 и оставалась видимой при обычных эффектах Sandbox. Диагностика:
renderers.txt, before-full.png и without-post.png. При отключении крупных спрайтов
силуэт исчезал; он не принадлежал музыкальному шейдеру.

Исправление: подложка создаётся из однотонной текстуры и включается только в
изолированном редакторе VFX. При закрытии редактора скрывается сразу. В обычном
Sandbox и при применении профиля способности подложка не выводится.

Звёзды Far/Mid без следа раньше имели ограниченную угловую скорость разворота,
как управляемые частицы. После смещения VP они могли описывать дугу. Теперь их
скорость задаёт вектор расширения относительно сглаженного EffectiveVP. Проход
центра через звезду не вызывает кружения. Позиции сохраняются, при нулевой скорости
поворот не переносит звёзды. Стрики сохраняют свой хвост и прежнее плавное поведение.

После уточнения пользователя весь музыкальный визуализатор привязан к центру курса:
root с кольцами/звёздами/свечением, центр процедурного шейдера, точки рождения дождя
и уже активные волны преломления. Рисунок колец, цвета и отклик на звук не изменены.
Отдельные декоративные линии Sandbox и сам босс не являются музыкальным слоем.

Исправлена также проверка сохранения Phase 1: она теперь восстанавливает целиком
исходный профиль в finally и не оставляет SteeringEnabled=false. В профиле возвращено
SteeringEnabled=true, как было до регрессионного запуска.

Проверки в Unity: verify.txt. Кадры after-center.png, music-*.png, after-game-view.png.
stars-motion.mp4 показывает только Far/Mid Stars без музыки и без стриков;
music-course.mp4 — весь игровой кадр при смене курса. Видео собраны из рендеров Unity
без дополнительной цветокоррекции. Проверены отсутствие подложки, редактор VFX,
геометрический и шейдерный центры, движение активных колец и отсутствие поворота
звёзд по дуге. Проверки относятся к текущему Windows Editor.

Итог: verify.txt — PASS. Регрессия SpaceDepth/stage-3.txt от 19:15 — PASS.
После её завершения сохранённый профиль действительно содержит SteeringEnabled=1.
